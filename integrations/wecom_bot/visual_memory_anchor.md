# 多模态视觉底座相册与身份锚点规范 (Visual Memory Anchor Guide)

> **核心目标**：当逝去亲友生前留存的清晰高清照片非常稀少时，大语言模型往往难以判断新发来的老照片、家庭合影中“谁是谁”。本规范指导如何利用少量（3~5 张）具有代表性的历史基准照片，辅助多模态视觉模型（如 Gemini Flash / GPT-4o）进行高精度的家庭人像比对、真伪判断与新记忆沉淀。

---

## 一、为什么需要“视觉锚点相册”？

1. **解决老旧模糊照片的身份确认**：
   过去的家庭相纸扫描件或早期智能手机照片分辨率有限，若单靠模型通用知识很难识别亲人五官。
2. **多视角与不同年龄段的基准特征**：
   亲人在年轻时、中年时、晚年时的发型、体态与衣着风格各有不同。
3. **避免胡乱认亲（幻觉抑制）**：
   有了底座锚点，当用户在聊天中发来一张新照片时，机器人能准确认出：“这是当年全家出海的照片”、“右边是阿姨，中间是你拉着我的手”，极大增强情感真实度。

---

## 二、推荐构建的 4 级基准锚点

建议在本地目录（如 `family_photos/`）下保存 3~5 张关键照片，并在配套文档中详细描述特征：

| 锚点类型 | 照片示例 | 关键视觉特征标注 | 作用与优势 |
| :--- | :--- | :--- | :--- |
| **1. 官方证件/免冠标准照** | `target_id_card.jpg` | 正面免冠、五官轮廓、眉形、眼皮、脸型比例 | 人脸五官比例与骨骼轮廓的绝对权威基准 |
| **2. 标志性个人全身/半身照** | `target_daily_portrait.jpg` | 习惯发型（如圆寸/偏分）、常戴配饰（腕表/墨镜）、身材体格（魁梧/清瘦） | 捕捉标志性体态、站姿与穿搭习惯 |
| **3. 社交与好友合影** | `target_with_friends.jpg` | 笑容神态、手势习惯、与同龄人的相对身材差异 | 捕捉自然放松状态下的面部表情细节 |
| **4. 核心家庭事件标志性合影** | `family_milestone_event.jpg` | 具体年代、地点（如某次旅行）、与晚辈/家人的互动姿态（如抱孩子） | 提供时空情境锚点，直接串联具体生活大事件 |

---

## 三、视觉 Prompt 注入模板 (供 AI Agent / 插件调用)

当用户在手机端向机器人发送图片时，网关将底座锚点描述动态注入提示词：

```markdown
【家庭人像视觉特征基准库】：
1. 纪念对象（如父亲）：标志性发型为寸头；身材魁梧硬朗；左手常年佩戴银色钢表；笑容温和。
2. 用户（如儿子）：青年男子，微胖，戴黑框眼镜。
3. 其他家人特征简述：...

【任务指令】：
请仔细观察用户刚刚发送的图片：
1. 画面中是否存在与上述基准特征匹配的亲友？
2. 如果存在，请以第一人称长辈的口吻温柔确认：“这是当年我们去...拍的吧”、“看到这张老照片真亲切”。
3. 如果识别到新的生活细节或家庭场景，自动生成一条结构化记忆存入记忆库。
```
